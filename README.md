# Алокатор пам'яті (ОС, лабораторна 2)

Моя реалізація мінімального алокатора пам'яті мовою C: функції `os_malloc()`, `os_calloc()`,
`os_realloc()` та `os_free()` поверх системних викликів `brk()`, `mmap()` і `munmap()`.

- Код рішення: [`src/osmem.c`](src/osmem.c)
